# boat-sdk-rs

An independent Rust client for the Boat VM API, intended to make Boat sandboxes
usable by Rust applications such as [Caelum](https://github.com/caelurium/caelum).

The SDK implementation is not started yet. Caelum's initial integration is tracked
in [issue #214](https://github.com/caelurium/caelum/issues/214).
